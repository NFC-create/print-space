PRINT SPACE — CARTE NFC DIGITALE
================================

OUVRIR DANS INTELLIJ IDEA

1. Décompressez le fichier ZIP.
2. Ouvrez IntelliJ IDEA.
3. Cliquez sur File > Open.
4. Sélectionnez le dossier Print-Space-NFC.
5. Dans le projet, faites un clic droit sur index.html.
6. Choisissez Open In > Browser.

Cette page fonctionne directement, sans npm et sans installation.
